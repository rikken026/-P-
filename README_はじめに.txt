森Pのゲームラウンジ — 20人のアイドル演出追加版
━━━━━━━━━━━━━━━━━━━━━━━

■ 今回追加したもの
・20人の主要キャラクターから自由に選べる画面
・キャラクターの個別のセリフ、勝利時のセリフ
・合成音声によるセリフ読み上げ（日本語／英語／中国語／韓国語）
・観客の歓声・拍手をイメージした音の演出
・無料の応援ギフト：ハート／薔薇／星／花束／ペンライト
・オンラインの部屋内でプレイヤーの選択キャラ・ギフトが同期
・勝利時に自動で架空のファンギフトが発生
・森Pのチュートリアル音声読み上げボタン
・声ON/OFF、歓声ON/OFF、音量スライダー

■ 1人で遊びたいとき
「public/solo.html」をブラウザーで開いて遊べます。
または別途お渡しした「森P_アイドル演出版_1人用.html」を使えば
ファイル1つだけで遊べます。

■ 友達とオンライン対戦するとき
「public/index.html」を直接開いただけでは複数人対戦になりません。
本フォルダー全体をWebサービスとして公開する必要があります。

【サーバー起動例：Node.js 20以上】
  npm install
  npm start
  → http://localhost:3000

【ネット公開の例】
1. このフォルダーの中身をGitHubのリポジトリーにアップロード
2. WebSocket対応のNode.jsホスティングサービス（例：Render）で
   Build: npm install / Start: npm start に設定
3. 公開URLをLINEで共有
4. 参加者はそれぞれニックネームと共通の合言葉を入力
5. 好きなキャラを選んで入室（最大4名）

※現在、実際の公開URLはありません。これは公開用のソース一式です。
※無料サーバーは休止・再起動で部屋とコインが消える場合があります。
※合言葉を知る人なら空きがある部屋に入れるため、長めの合言葉を推奨。
※本名・メールアドレス・電話番号は入力不要です。

■ 音声と画像
音声：端末やブラウザーの読み上げ機能を使用。
日本語／英語／中国語／韓国語の声質・対応状況は端末依存。
音声ファイルのダウンロードや外部有料サービスは不要です。
初回はキャラの「セリフを試す」等を押して音声を有効にしてください。
歓声はゲーム内で合成した効果音（録音された観客音声ではありません）。
画像：20人の画像は以前のコンセプト画面から切り出した試作用のものです。
森Pはご提供の「白い丸顔・黒サングラス・紺系スーツ」の画像です。

■ ゲームについて
・麻雀、おいちょかぶ、51ポーカー、ルーレット＆サイコロ、買い物スロット
・前回のオリジナル特殊ルールを継続
・架空コイン限定。販売・換金・送金・賞品交換は一切ありません。
・ギフトも完全無料。コイン残高や勝敗、確率に影響しません。
・キャラクターの多様な背景は娯楽表現の一部です。
・オンライン版は通信サーバーを経由する試作版です。
