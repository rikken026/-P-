森Pのゲームラウンジ スマホ操作改善版

【まずは新しいZIPに差し替え】
1. morip_game_publish_mobile.zip を保存して「すべて展開」します。
2. 以前のZIPや解凍フォルダーはそのまま保管して構いません。
3. 今回展開したフォルダーを開きます。package.json、server.js、public フォルダーが見える場所がアップロード元です。

【GitHubへ】
4. 作成したリポジトリを開きます。
5. Add file → Upload files を選びます。空のリポジトリなら「uploading an existing file」から進めます。
6. 今回展開したフォルダーの「中身をすべて」ドラッグします。public フォルダーも丸ごと含めます。ZIPそのものや外側のフォルダーをアップロードしないでください。
7. Commit changes で保存します。
8. リポジトリの最初の画面に package.json、server.js、render.yaml、public が並ぶことを確認します。
すでに旧版をアップロードしている場合も、同じ場所へ新版の中身をアップロードして更新してください。

【Renderへ】
9. New → Web Service から、そのGitHubリポジトリを選びます。
10. Runtime：Node、Build Command：npm install、Start Command：npm start を設定します。
11. Root Directory は空欄のままにします。利用プランと画面の料金表示を確認して作成します。
12. 起動後に表示される https://～onrender.com のURLを開きます。
すでにRenderへ接続している場合は更新のデプロイを確認します。自動更新されない設定なら Manual Deploy で最新のコミットを選びます。

【遊び方の変更】
・手牌は48×68px。小さく縮めず折り返します。
・牌を押すと黄色く選択されます。「この牌を捨てる」で確定します。別の牌を押すと選び直せます。
・スマホでは、現在使える操作を画面下に表示します。
・PCでは通常のボタンと、手牌選択後の確定ボタンを使います。
・選択後に対戦状態が更新されたときは、誤操作防止のため牌を選び直してください。
・1人用は public/solo.html を開くだけでも遊べます。

【維持した内容】
20人のキャラクター画像、森P画像、4言語、端末の読み上げ音声、歓声・効果音、無料応援ギフト、5ゲーム、オンライン対戦のルールと通信処理。
森Pおよび人物画像は元のZIPの画像をそのまま使っています。

【確認範囲】
WindowsのEdgeによるブラウザー確認：幅360・390・768・1366px。
4つのブラウザー接続でオンライン入室、麻雀の選択→確定→次の手番、5ゲームの開始・主要操作、4言語切替を確認。
1人用で麻雀の選択→確定、5ゲーム表示、4言語切替、20人の選択肢を確認。
既存のサーバーテストも合格。画像21点とサーバー・音声応援処理は元版と同一です。
スマホ実機のSafari/Chrome、離れた端末同士の通信、Renderへの本番公開は未確認です。公開後はご自身のスマホと友達の端末で同じ合言葉で入室し、音声とタップ操作を確認してください。
1人用の初回コインが0になる元版の読み込み処理も修正し、初回1,000枚で開始します。
